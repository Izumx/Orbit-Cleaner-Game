# 🛰️ OrbitClean — Orbit Cleaner Game

Интерактивная браузерная 3D-платформа про космический мусор. Вращающаяся фотореалистичная Земля, вокруг которой по **реальным орбитам** летает рой из 10 000+ отслеживаемых объектов — спутники, ступени ракет и обломки. Кликаешь на объект, видишь реальные данные о нём и отвечаешь на вопрос по физике/космосу — правильный ответ «очищает» орбиту и приносит очки.

> Образовательная «залипалка», которая наглядно показывает масштаб проблемы космического мусора и синдрома Кесслера.

**Developed by Eskendir Bakhitzhanov** · для хакатона [StarDance](https://stardance.hackclub.com/) (Hack Club)

## ✨ Ключевые фичи

- 🌍 **Фотореалистичная Земля** — текстуры NASA Blue Marble, ночные огни городов, облака, рельеф, движущийся терминатор день/ночь
- 🌌 **Атмосфера и звёзды** — fresnel-свечение по краю планеты, звёздное небо, кинематографичный bloom
- 🛰️ **Рой 10 000+ реальных объектов** — реальные орбиты из TLE (CelesTrak), расчёт SGP4 через satellite.js в Web Worker, рендер через `InstancedMesh` на 60fps
- 🎮 **Геймплей** — клик по объекту → карточка с реальными данными + вопрос, привязанный к этим данным → очистка орбиты и очки
- 📊 **Kessler-meter** — индикатор перегруженности орбиты, который снижается по мере очистки
- 🏆 **Лидерборд** — общий рейтинг игроков (стретч-цель)

## 🛠️ Технологии

| Слой | Стек |
|------|------|
| Сборка | Vite + React + TypeScript |
| 3D | react-three-fiber (R3F) + drei + @react-three/postprocessing |
| Орбиты | satellite.js (SGP4) в Web Worker |
| Данные орбит | [CelesTrak](https://celestrak.org/) (TLE/GP) |
| Текстуры Земли | NASA Blue Marble |
| Бэкенд / БД | Supabase (Postgres + Auth + лидерборд) |

> **Об источниках данных:** каталог отслеживаемых объектов берётся из CelesTrak / Space-Track (US Space Force). От NASA используются текстуры Земли. Источники указаны честно.
